A time widget in HTML, CSS, and JavaScript to put on your website as an embeddable, inline frame made by [udrr](https://github.com/udrr).
## C://:usage
Click the <code>Clock Settings</code> on the top right to open up a configuration panel to customize the clock in the center. Any changes get automatically added to localStorage so you can view your changes again.
| Option | What it does |
| --- | --- |
| Quotes? | Hide quotes above clock if false |
| Sounds? | Turns off the automatic "tick" sound when the second hand moves (note: for sound, make sure the user interacts with either the frame or the website first.) |
| Page Background | Changes page background color |
| Clock Face Color | Changes the background of the clock where the hands move |
| Hour Hand Color | Changes the color of the hour hand |
| Minute Hand Color | Changes the color of the minute hand |
| Second Hand Color | Changes the color of the second hand |
| Text Color | Changes the color of the text |
| Title Text | Changes title text (on default, the title text is the [TIME TRIGGER WIDGET] in the top left) |

Once you're happy with your time widget, copy and paste the shareable URL and put it in an iframe like so:
```
<iframe src="//udrr.github.io/time-trigger-widget?<your-config-settings>&embed=true" style="border: none;" width="700" height="700" title="TIME TRIGGER WIDGET" loading="lazy"></iframe>
```
